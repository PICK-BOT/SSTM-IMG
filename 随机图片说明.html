1 新增图片到随机池

1
打开 GitHub · manifest.json，点右上角的 ✏️ 铅笔图标 进入编辑模式。
2
在 JSON 数组末尾加入新图片 URL（注意格式，每行一条，用逗号分隔，最后一条不加逗号）： 
[
  "https://s.sstmlt.com/img/xxx/图片1.png",
  "https://s.sstmlt.com/img/xxx/图片2.png",
  "https://s.sstmlt.com/img/xxx/图片3.png"
]
3
点页面右上角绿色的 Commit changes 按钮保存。
⚠️ Worker 会缓存 manifest.json 最多 5 分钟，新图片最多 5 分钟后生效。

2 manifest.json 格式规则

这是一个标准 JSON 数组，只放图片的完整 URL 字符串：

[
  "https://图片地址1.png",   ← 有逗号
  "https://图片地址2.jpg",   ← 有逗号
  "https://图片地址3.gif"    ← 最后一条没有逗号
]
❌ 常见错误：最后一项后面多了逗号，会导致 JSON 解析失败，图片全部消失。
✅ 图片格式支持：png / jpg / gif / webp（只要是直链都可以）

3 Worker 代码（防缓存版本）

如果 F5 后图片不变，到 Cloudflare Dashboard → Workers → sstmimg → Edit Code，确认代码如下：

export default {
  async fetch(request) {
    const manifestUrl =
      'https://raw.githubusercontent.com/PICK-BOT/SSTM-IMG/main/manifest.json';
    try {
      const res = await fetch(manifestUrl, { cf: { cacheTtl: 300 } });
      const images = await res.json();
      if (!Array.isArray(images) || images.length === 0)
        return new Response('No images', { status: 404 });

      const url = images[Math.floor(Math.random() * images.length)];
      return new Response(null, {
        status: 302,
        headers: {
          'Location': url,
          'Cache-Control': 'no-store, no-cache, must-revalidate',
          'Pragma': 'no-cache',
        },
      });
    } catch (e) {
      return new Response('Error: ' + e.message, { status: 500 });
    }
  },
};

4 如何获取图片直链

A
从 sstmlt.com 上传图床
上传图片后，右键复制图片地址，格式通常是 https://s.sstmlt.com/img/年/月/日/xxxx.png
B
从其他图床（Imgur、SM.MS 等）
上传后选择「Direct link」直链，必须以图片扩展名结尾（.jpg / .png / .gif）。
⚠️ 不要用 Google Drive 或 OneDrive 分享链接，无法作为 img src 直接显示。
